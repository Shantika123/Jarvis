JARVIS – Personal AI Voice Assistant 
Technologies Used : Python, SpeechRecognition, pyttsx3, psutil, OpenWeatherMap API, 
WolframAlpha API, Wikipedia API 
Developed a Python-based virtual assistant that performs voice-controlled tasks like opening 
apps, searching the web, fetching weather info, and answering questions. Integrated APIs 
(OpenWeatherMap, WolframAlpha, Wikipedia) and automated desktop apps using speech 
recognition and system commands.
