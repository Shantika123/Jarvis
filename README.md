# Jarvis AI – Python Voice Assistant 

Jarvis AI is a simple **Python-based voice assistant** that can perform tasks such as opening applications, searching the web, telling the time, and responding to voice commands.
The project demonstrates the use of **speech recognition, text-to-speech, and automation in Python**.

---

## Features

* Voice command recognition
* Text-to-speech response
* Open websites (Google, YouTube, etc.)
* Tell current time
* Open local applications
* Perform web searches
* Basic conversational responses

---

## Tech Stack

* **Python**
* **SpeechRecognition**
* **pyttsx3**
* **PyAudio**
* **Webbrowser**
* **Datetime**
* **OS module**

## Installation

### 1️)Clone the repository

```bash
git clone https://github.com/your-username/jarvis-ai.git
cd jarvis-ai
```

### 2️) Install dependencies

```bash
pip install -r requirements.txt
```

### 3️) Manual Installation (If requirements.txt is not available)
If `requirements.txt` is not available, install manually:

```bash
pip install SpeechRecognition pyttsx3 pyaudio
```

---

## Running the Project

Run the main script:

```bash
python jarvis.py
```

After running, Jarvis will start listening for voice commands.
